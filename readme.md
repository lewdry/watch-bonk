# Bonk: Colourful Balls ⌚🎨

A simple, minimalist Garmin watch face with a colourful twist.

Bonk shows the time and nothing else, until you raise your wrist. Then colourful balls appear, different sizes and colors every time. Let your watch sleep, and they disappear.

*Business in front, balls in the back(ground).*

## Features

- Clean, minimalist time display
- Colourful balls on wrist raise
- Light and dark mode support
- **Always Balls** mode in settings

## Install

Get it from the Garmin Connect IQ Store:

[Bonk - Colourful balls](https://apps.garmin.com/apps/405a84aa-987e-4aae-95f0-06c238b56641)

## Settings

| Setting | Description |
|---|---|
| Theme | Light / Dark mode |
| Always Balls | Keeps the colourful balls visible permanently instead of only on wrist raise |
